"Do not save the DataFrame's index as a separate column in the output file."



🔹 With index=False

╭────────────────────────────────────╮
│ 		🌟🔄 INPLACE KEYWORD🌟    		        │
╰────────────────────────────────────╯



When we use inplace=True in a Pandas operation, the operation is applied directly to the original DataFrame or Series, and the original data is modified.


df.dropna(inplace=True)


Here, the missing-value rows are removed from the original df itself.




🔹----------------------------------------------------------🔹
		Without inplace=True
🔹-----------------------------------------------------------🔹

df.dropna()

The operation returns a new DataFrame, while the original df remains unchanged unless we assign the result:

df = df.dropna()




🔹----------------------------------------------------------🔹
		With inplace=True
🔹-----------------------------------------------------------🔹

df.dropna(inplace=True)

The original df is modified directly.





🧠 Easy way to remember

🔹inplace=False  → Original data stays unchanged

🔹inplace=True   → Original data is modified

▓▒░ 💻 CONCAT - WHEN ALL COLUMNS ARE SAME IN BOTH DATAFRAMES ░▒▓


📌 WHAT IS concat()?

concat() is used to combine two or more DataFrames along rows or columns.

When two DataFrames have the same columns, we can use pd.concat() to add the rows of one DataFrame below the other.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Syntax

pd.concat([df1, df2])

Here, df1 and df2 are the DataFrames you want to combine.






📌 HOW DOES IT WORK?

Suppose:

df1 → Name, Age, Salary, Department, Experience

df2 → Name, Age, Salary, Department, Experience

Both DataFrames have the same columns.

When we use:

pd.concat([df1, df2])

Pandas puts the rows of df2 below the rows of df1.

df1
 ↓
Rows 0, 1, 2, 3

       +

df2
 ↓
Rows 0, 1, 2, 3

       ↓

Final DataFrame
 ↓
Rows from df1
+
Rows from df2








👉🏻Example:


import pandas as pd
df1 = pd.DataFrame({
    "Name": ["Arshad", "Aatif", "Abhijeet", "Ashu"],
    "Age": [26, 23, 24, 25],
    "Salary": [24000, 28000, 18000, 16000],
    "Department": ["Support", "AI Developer", "Networking", "Cloud"],
    "Experience": [1.4, 2, 1.2, 1]
})

df2 = pd.DataFrame({
    "Name": ["Manu", "Rashi", "Taukir", "Sid"],
    "Age": [27, 25, 24, 26],
    "Salary": [12000, 22000, 18000, 14000],
    "Department": ["Process", "Marketing", "Cloud", "Business"],
    "Experience": [0, 1.4, 1.3, 2]
})


# Merge both data frame
final_list = pd.concat([df1, df2])
print(final_list)

▓▒░ 💻 MERGE METHOD - WHEN COLUMNS ARE DIFFERENT IN DATAFRAMES ░▒▓


📌 WHAT IS MERGE()?

merge() is used to combine two DataFrames based on one or more common columns.

It is similar to a JOIN operation in SQL.

👉 The two DataFrames do NOT need to have the same columns.

They only need to have a common column that can be used to match the rows.




━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📌 SYNTAX

pd.merge(df1, df2, on="column_name")

Means:
"Take df3 and df4, find rows where Name is the same, and combine their data."

Where:

🔹 df1 → First DataFrame
🔹 df2 → Second DataFrame
🔹 on="column_name" → Common column used to match rows

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━



How It works:

If we pass on="Name", it finds the all the columns and its data of common name like in this given data-frames "Aatif" & "Arshad" name are available in both data-frames, so It returns all the columns along with its values & It discard the unique names




📌Example:


import pandas as pd
df3 = pd.DataFrame({
    "Name": ["Arshad", "Aatif", "Abhijeet", "Ashu"],
    "Age": [26, 23, 24, 25],
})
print(df3)
print()

df4 = pd.DataFrame({
    "Name": ["Aatif", "Arshad", "Taukir", "Sid"],
    "Salary": [12000, 22000, 18000, 14000],
})
print(df4)
print()

# Merge both data frame
final_list1 = pd.merge(df3, df4, on="Name")
print(final_list1)
