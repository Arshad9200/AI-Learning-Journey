▓▒░ 💻 What is a DataFrame?   ░▒▓


A DataFrame is a two-dimensional (2D), labeled data structure in Pandas.

It looks similar to an Excel spreadsheet or a SQL table, containing:

A DataFrame can contain different data types in different columns.


📊 Rows
📋 Columns
🏷️ Row indexes
🏷️ Column names
🔢 Values



📌 Simple Example

       Name    		   Age   		 City

0      Ali     		    22    		Delhi
1      Sara    		    24    		Mumbai
2      John    		    21    		Lucknow


Here:

🔹Name, Age, City 	→	 Columns
🔹0, 1, 2 				→ 	  Row Index
🔹Each row represents one record
🔹Each column represents one attribute







▓▒░ 💻  Structure of  Data Frame  ░▒▓





Consider this DataFrame:

📌Example

import pandas as pd

df = pd.DataFrame({"Name": ["Arshad", "Aatif", "Abhijeet"], "Age": [25, 24, 25], "Salary": [24000, 28000, 18000]})

print(df)
print(type(df))


📍Output

       Name  Age  Salary

0    Arshad   25   24000
1     Aatif      24   28000
2    Abhijeet   25   18000

<class 'pandas.core.frame.DataFrame'>





The structure is:

             Columns
           ↓          ↓       ↓
       Name    Age     Marks
        ↓       ↓       ↓
Index   Values
  ↓
  0      Ali     22      85
  1      Sara    24      90
  2      John    21      78

🚀 Creating a DataFrame ---------------

There are several ways to create a DataFrame.






━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
		1️⃣ DataFrame from Dictionary
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━


This is one of the most common methods.

import pandas as pd

data = {
    "Name": ["Ali", "Sara", "John"],
    "Age": [22, 24, 21],
    "Marks": [85, 90, 78]
}

df = pd.DataFrame(data)

print(df)



📍Output
   Name  Age  Marks
0   Ali       22     85
1  Sara     24     90
2  John     21     78


📌 Important

🔹Dictionary keys become column names.

🔹Dictionary values become column data.

"Name"  → Column
"Age"   → Column
"Marks" → Column

		2️⃣ DataFrame from List
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━


You can create a DataFrame using a list of lists.

import pandas as pd

data = [
    ["Ali", 22, 85],
    ["Sara", 24, 90],
    ["John", 21, 78]
]

df = pd.DataFrame(
    data,
    columns=["Name", "Age", "Marks"]
)

print(df)

📍Output:

   Name  	Age  	Marks
0   Ali   	  22     	   85
1  Sara   	   24    	    90
2  John   	    21    	     78

▓▒░ 💻 SELECTING SINGLE COLUMNS  ░▒▓


You can select a single column using its name.

Example:

import pandas as pd

df = pd.DataFrame({"Name": ["Arshad", "Abhijeet", "Aatif", "Ashu"], "Age": [26, 24, 23, 35], "Married": [False, False, False, False]})

print(df["Name"])



Output:

0      Arshad
1    Abhijeet
2       Aatif
3        Ashu
Name: Name, dtype: object

📍Notice that the result is a Series.



💡Important Concept

DataFrame
   ↓
Select one column
   ↓
Series







▓▒░ 💻 SELECTING MULTIPLE COLUMNS  ░▒▓


Use a list of column names inside double square brackets.

Example:

import pandas as pd

df = pd.DataFrame({"Name": ["Arshad", "Abhijeet", "Aatif", "Ashu"], "Age": [26, 24, 23, 35], "Married": [False, False, False, False]})

print(df[["Name", "Age"]])




📌Output:

       Name    Age
0    Arshad     26
1  Abhijeet     24
2     Aatif        23
3      Ashu       35

👉🏻The result is still a DataFrame.



💡Remember

🔸Single Column → df["Name"]     →    ➡️ Series

🔸Multiple Columns  →  df[["Name", "Marks"]] → ➡️ DataFrame

▓▒░ 💻 ILOC METHOD  ░▒▓



--------------------------------------------
✅Selecting Single Rows✅
--------------------------------------------

iloc selects data based on integer position.
iloc uses row/column position numbers, starting from 0.


Example:

import pandas as pd

df = pd.DataFrame({"Name": ["Arshad", "Abhijeet", "Aatif", "Ashu"], "Age": [26, 24, 23, 35], "Married": [False, False, False, False]})

print(df.iloc[2])


📌Output

This selects the third row.

Output:

Name       Aatif
Age           23
Married    False
Name: 2, dtype: object









------------------------------------------------------
   ✅Selecting Multiple Rows✅
-------------------------------------------------------


Example:

import pandas as pd

df = pd.DataFrame({"Name": ["Arshad", "Abhijeet", "Aatif", "Ashu"], "Age": [26, 24, 23, 35], "Married": [False, False, False, False]})

# Selecting multiple rows
print(df.iloc[1:3])




📌Output:

       Name  Age  Married
1  Abhijeet   24    False
2     Aatif      23    False










▓▒░ 💻 LOC METHOD  ░▒▓


loc selects data based on labels or indexes or custom index.
loc uses the actual row/column labels.


-----------------------------------------------
🏷️ Selecting Data Using loc
-----------------------------------------------

loc is used for labels (index)



💡 Selecting rows by default index number ---------------


Example:

import pandas as pd
data = {"Name": ["Arshad", "Abhijeet", "Aatif", "Ashu"], "Age": [26, 24, 23, 35], "Married": [False, False, False, False]}

df = pd.DataFrame(data)

print(df.loc[1])



📌 Output:

Name       Abhijeet
Age              24
Married       False
Name: 1, dtype: object










💡 Selecting rows by Custom index  ---------------


Example:

data = {"Name": ["Arshad", "Abhijeet", "Aatif", "Ashu"], "Age": [26, 24, 23, 35], "Married": [False, False, False, False]}

df = pd.DataFrame(data, index = ["frnd1", "frnd2", "frnd3", "frnd4"])

print(df.loc["frnd2"])


📌Output:

Name       Abhijeet
Age              24
Married       False
Name: frnd2, dtype: object







💡 Selecting Multiple rows by Custom index/default index  ---------------


Example:

import pandas as pd

data = [
    {"Name": "Arshad", "Salary": 24000, "Dept": "SaaS", "Exp": 1.4},
    {"Name": "Ashu", "Salary": 18000, "Dept": "AWS", "Exp": 1.2},
    {"Name": "Abhijeet", "Salary": 18000, "Dept": "Cloud", "Exp": 1.3},
    {"Name": "Aatif", "Salary": 29000, "Dept": "AI/ML", "Exp": 2}
]

df = pd.DataFrame(data, index = ["A", "B", "C", "D"])


print("Third & Fourth Rows:\n", df.loc[["C", "D"]]) 		# fetch multiple rows based on custom Index


📌Output:

Third & Fourth Rows:
        Name  Salary   Dept  Exp
C  Abhijeet   18000  Cloud  1.3
D     Aatif   29000  AI/ML  2.0










⭐ Remember

iloc → i = integer → Data POSITION
loc  → label → Custom Index / LABEL

For example:

df.iloc[1, 2]

means 2nd row, 3rd column.



df.loc["B", "Salary"]

means row "B", column "Salary".

-----------------------------------------------------
	✅🔎 Filtering Data✅
-----------------------------------------------------



📍Single Condition -------------------


Filtering is one of the most important operations in Pandas.

Suppose:

import pandas as pd

data = {"Name": ["Arshad", "Aatif", "Abhijeet"], "Age": [26, 24, 25], "Marks": [92, 91, 89]}

df = pd.DataFrame(data)

print(df[df["Age"] > 24])




📌Output:

       	   Name  Age  Marks
0    	Arshad     26     92
2  	Abhijeet   25     89





💡 How it works


df["Marks"] > 80

creates a Boolean Series:

True
False
True

Pandas then returns only the rows where the condition is True.











📍Multiple Condition -------------------


💫Using AND (&)  Operator
------------------------------------------

Example:

import pandas as pd

data = {"Name": ["Arshad", "Aatif", "Abhijeet"], "Age": [26, 24, 25], "Marks": [92, 91, 99]}

df = pd.DataFrame(data)

print(df[(df["Age"] > 24) & (df["Marks"] > 90)])


📌 Output:

       Name  Age  Marks
0    Arshad   26     92
2  Abhijeet   25     99






💫Using OR (|)  Operator
------------------------------------------

Example:

import pandas as pd

data = {"Name": ["Arshad", "Aatif", "Abhijeet"], "Age": [26, 24, 25], "Marks": [92, 91, 99]}

df = pd.DataFrame(data)

print(df[(df["Age"] < 25) | (df["Marks"] > 95)])



📌 Output:

       Name  Age  Marks
1     Aatif   24     91
2  Abhijeet   25     99

------------------------------------------------------------------------
  ✅SORT BY COLUMN (sort_values())✅
------------------------------------------------------------------------


📍Ascending Order ----------


By Default, It sort the data in ascending order

📌Example:

import pandas as pd
data = {"Name": ["Arshad", "Aatif", "Abhijeet"], "Age": [26, 24, 25], "Marks": [92, 91, 99]}
df = pd.DataFrame(data)

print(df.sort_values("Marks"))



📌Output:

          Name  Age  Marks
1       Aatif       24     91
0       Arshad   26     92
2  	Abhijeet   25     99








📍Descending Order ----------


📌Example:

import pandas as pd
data = {"Name": ["Arshad", "Aatif", "Abhijeet"], "Age": [26, 24, 25], "Marks": [92, 91, 99]}
df = pd.DataFrame(data)

print(df.sort_values("Marks", ascending=False))



📌Output:

       Name  Age  Marks
2  Abhijeet   25     99
0    Arshad   26     92
1     Aatif   24     91

       		   🧹 MISSING VALUES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━


DataFrames often contain missing values.
isnull() methods return the True value where data is missing/not a number.


------------------------------------------------------------------------
✅CHECK MISSING VALUE (isnull())✅
------------------------------------------------------------------------



📍 Example:

import pandas as pd
import numpy as np
data = {"Name": ["Arshad", "Aatif", "Abhijeet"], "Age": [26, np.nan, 25], "Marks": [92, 91, 99]}
df = pd.DataFrame(data)

print(df.isnull())




📌Output:

    Name    Age  Marks
0  False  False  False
1  False   True  False
2  False  False  False






------------------------------------------------------------------------
	✅COUNT MISSING VALUE✅
------------------------------------------------------------------------

📌Example:

import pandas as pd
import numpy as np
data = {"Name": ["Arshad", "Aatif", "Abhijeet"], "Age": [26, np.nan, 25], "Marks": [92, 91, 99]}
df = pd.DataFrame(data)

print(df.isnull().sum())


📌Output:

Name     0
Age      1
Marks    0
dtype: int64









--------------------------------------------------------------------------------------------------------------
		🗑️REMOVING  MISSING VALUE✅
--------------------------------------------------------------------------------------------------------------

This removes rows containing missing values.

📌Example:

import pandas as pd
import numpy as np
data = {"Name": ["Arshad", "Aatif", "Abhijeet"], "Age": [26, np.nan, 25], "Marks": [92, 91, 99]}
df = pd.DataFrame(data)

df = df.dropna()
print(df)



📌Output:

       Name   Age  Marks
0    Arshad  26.0     92
2  Abhijeet  25.0     99






--------------------------------------------------------------------------------------------------------------
	🔧INSERTING 0 IN PLACE OF MISSING VALUE✅
--------------------------------------------------------------------------------------------------------------



👉INSERT 0 AT SINGLE COLUMN👈


📌 Example:

import pandas as pd
import numpy as np
data = {"Name": ["Arshad", "Aatif", "Abhijeet"], "Age": [26, np.nan, np.nan], "Marks": [92, 91, 99]}
df = pd.DataFrame(data)

df["Age"] = df["Age"].fillna(0)
print(df)




📌 Output

       Name   	Age  	Marks
0    Arshad  	26.0            92
1     Aatif   	0.0    	  91
2  Abhijeet   	0.0    	  99


💡 In Age column, Now the missing mark is replaced with 0.








👉INSERT 0 AT MULTIPLE COLUMNS👈


📌 Example:


import pandas as pd
import numpy as np

data = {
    "Name": ["Arshad", "Atif", "Abhijeet", "Ashu"],
    "Salary": [24000, 29000, np.nan, 18000],
    "Dept": ["Saas", "AI/ML", "Cloud", np.nan]
}

df = pd.DataFrame(data, index=["A", "B", "C", "D"])
print(df)

df[["Salary", "Dept"]] = df[["Salary", "Dept"]].fillna(0)

print("Insert 0 at columns containg Null Values\n", df)
