🧠 Real-World Example




Imagine an employee dataset:



import pandas as pd

emp_data = {
    "Name": ["Arshad", "Aatif", "Abhijeet", "Ashu"],
    "Age": [26, 23, 24, 25],
    "Salary": [24000, 28000, 18000, 16000],
    "Department": ["Support", "AI Developer", "Networking", "Cloud"],
    "Experience": [1.4, 2, 1.2, 1]
}

df = pd.DataFrame(emp_data)

print(df)

3      Ashu   	 25   		16000         	 Cloud         		    1.0
