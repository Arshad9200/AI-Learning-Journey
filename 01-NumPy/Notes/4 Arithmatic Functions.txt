📌 Definition

NumPy provides several built-in arithmetic functions to perform mathematical operations on arrays.

These functions perform operations element-wise, meaning each element of one array is operated on with the corresponding element of another array.




╭──────────────────────────────╮
│ 		🌟 1. MIN & MAX  🌟 				│
╰──────────────────────────────╯




📝 Example

import numpy as np
var = np.array([13, 6, 9, 12])
print("Minimum:",np.min(var))
print("Maximum:",np.max(var))


📌 Output

Minimum: 6
Maximum: 13








╭──────────────────────────────╮
│ 	🌟 2. POSITION OF MIN & MAX  🌟 		│

Position of Maximum: 1









╭────────────────────────────────────────╮
│🌟 3. Find the Minimum and Maximum Value in a 2-D Array 🌟 │
╰────────────────────────────────────────╯


🟢 Row-wise Operation (axis=1)🟢 

When axis=1 is used, NumPy performs the operation row by row.

💡 Trick:
Number of output values = Number of rows


🔹 Minimum Value (np.min(axis=1)) ---------------

Row 1  [13, 20, 119, 10] → Minimum = 10
Row 2  [40, 10, 30, 1]     → Minimum = 1
Row 3  [14, 12, 32, 0]     → Minimum = 0

📌 Output
[10  1  0]




🔹 Maximum Value (np.max(axis=1))

Row 1	[13, 20, 119, 10] → Maximum = 119
Row 2	[40, 10, 30, 1] → Maximum = 40
Row 3	[14, 12, 32, 0] → Maximum = 32

📌 Output
[119  40  32]


📝 Example
import numpy as np

var1 = np.array([
    [13, 20, 119, 10],
    [40, 10, 30, 1],
    [14, 12, 32, 0]
])
print("Minimum:", np.min(var1, axis=1))
print("Maximum:", np.max(var1, axis=1))

📌 Output
Minimum: [10  1  0]
Maximum: [119  40  32]








🟢 Column-wise Operation (axis=0) 🟢 


📌 Definition

When axis=0 is used, NumPy performs the operation column by column.

💡 Trick:
Number of output values = Number of columns


🔹 Minimum Value (np.min(axis=0)) ---------------

Column 1		[13, 40, 14]   → Minimum = 13
Column 2		[20, 10, 12]   → Minimum = 10
Column 3		[119, 30, 32]  → Minimum = 30
Column 4		[10, 1, 0] 	     → Minimum = 0

📌 Output
[13 10 30  0]


🔹 Maximum Value (np.max(axis=0)) --------------------

Column 1		[13, 40, 14]    → Maximum = 40
Column 2		[20, 10, 12]    → Maximum = 20
Column 3		[119, 30, 32]   → Maximum = 119
Column 4		[10, 1, 0] 	      → Maximum = 10

📌 Output
[ 40  20 119  10]


📝 Example

import numpy as np

var1 = np.array([
    [13, 20, 119, 10],
    [40, 10, 30, 1],
    [14, 12, 32, 0]
])
print("Minimum:", np.min(var1, axis=0))
print("Maximum:", np.max(var1, axis=0))

📌 Output
Minimum: [13 10 30  0]
Maximum: [ 40  20 119  10]










Minimum-----

first row [13, 20, 119, 10]  →  return 10 (min)
second row [40, 10, 30, 1]  →  return 1 (min)
third row [14, 12, 32, 0]  →  return 0 (min)
Min Output  [10, 1, 0]


Maximum -----

first row [13, 20, 119, 10]  →  return 119 (max)
second row [40, 10, 30, 1]  →  return 40 (max)
third row [14, 12, 32, 0]  →  return 32 (max)
Min: Output  [10, 1, 0]

Min: Output  [119, 40, 32]

import numpy as np

✨ What Happens If We Do Not Pass axis?
-----------------------------------------------------------------------

📌 Definition

If you do not specify the axis parameter, NumPy treats the entire array as a single collection of elements.

It does not perform row-wise or column-wise operations.

💡 Trick:
No axis = Whole array is considered.


📝 Example

import numpy as np
var1 = np.array([
    [13, 20, 119, 10],
    [40, 10, 30, 1]])
print(var1)
print("Minimum:", np.min(var1), "Position:", np.argmin(var1))
print("Maximum:", np.max(var1), "Position:", np.argmax(var1))


📌 Output
[[ 13  20 119  10]
 [ 40  10  30   1]]
Minimum: 1 Position: 7
Maximum: 119 Position: 2


💡 Explanation

NumPy looks at all the elements in the single array, it means 13 considered as first element (0th index) , 1 considered as last element (7th index).

╭────────────────────────────────────────╮
│			🌟7. CUMSUM FUNCTION 🌟 				  │
╰────────────────────────────────────────╯



📌 Definition

The np.cumsum() function is used to calculate the cumulative (running) sum of the elements in an array.

💡 Running Sum: Each value is the sum of the current element and all previous elements.



📌 Syntax 	np.cumsum(array, axis=None)

📖 Parameters

array → Input array.
axis (optional) → Specifies the axis along which the cumulative sum is calculated.
No axis → Entire array.
axis=0 → Column-wise.
axis=1 → Row-wise.






✨ Example 1: 1-D Array ────────


📝 Example

import numpy as np
var1 = np.array([1, 2, 3, 5, 7])
print("Value of cumulative sum:",np.cumsum(var1))


📌 Output

Value of cumulative sum: [ 1  3  6 11 18]


💡 Explanation
1       	 = 1
1 + 2         = 3
3 + 3   	 = 6
6 + 5   	 = 11
11 + 7 	 = 18





✨ Example 2: 2-D Array (No axis) ─────────────


📝 Example

import numpy as np
var1 = np.array([
    [1, 2, 3],
    [5, 7, 8]])
print("Value of cumulative sum:",np.cumsum(var1))

📌 Output

Value of cumulative sum: [ 1  3  6 11 18]


💡 Explanation
Without axis, NumPy first flattens the array:
It consider both row elements as a single row elements






✨ Example 3: Row-wise (axis=1) ────────────

📝 Example
