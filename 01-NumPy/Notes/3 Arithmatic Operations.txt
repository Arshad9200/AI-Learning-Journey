📌 Definition

NumPy allows you to perform arithmetic operations directly on arrays without using loops.

These operations are performed element-wise, meaning each element in one array is operated on with the corresponding element in the other array.





✨ Types of Arithmetic Operations
──────────────────────

➕ Addition
➖ Subtraction
✖️ Multiplication
➗ Division
🟰 Modulus (Remainder)
🔼 Power (Exponentiation)











=================
1-DIMENSION ARRAY
=================




╭────────────────────────────────────────╮
│				🌟 1. Addition (+) 🌟 					  │
╰────────────────────────────────────────╯


▫️Add Single Number of the each element of the Array ---------------

📝 Example

import numpy as np
var1 = np.array([2, 4, 6, 8])
var2 = var1 + 10      or    res_var = np.add(var1, 4)
print("var1:", var1)
print("var2:", var2)

📌 Output

var1: [2 4 6 8]
var2: [12 14 16 18]


Note: 
This method is used when we have to add same number to each element



▫️Add Array with another Array ---------------

📝 Example

import numpy as np
var3 = np.array([2, 4, 6, 8])
var4 = np.array([10, 10, 10, 10])
sum_res = var3 + var4     or    res_var = np.add(var3, var4)
print("Addition:", sum_res)

📌 Output

Addition: [12 14 16 18]


Note: 
This method is used when we have to add different number to each element

╭────────────────────────────────────────╮
│				🌟7. Reciprocal (1/a) 🌟 				  │
╰────────────────────────────────────────╯



▫️Find Exponential (Power) of the each element of the Array ---------------

📝 Example

import numpy as np
var1 = np.array([2, 4, 6, 8])
rec_res = 1/var1                    or rec_res = np.reciprocal(var1)
print("Reciprocal:", rec_res)


📌 Output

Reciprocal: [0.5        0.25       0.16666667 0.125     ]



Method  
rec_res = np.reciprocal(var1)

📌 Output
Reciprocal: [0 0 0 0]
⚠️ Why is the output [0 0 0 0]?

var1 is an integer array, so np.reciprocal() performs integer reciprocal:

1/2 = 0.5 → stored as 0
1/4 = 0.25 → stored as 0
1/6 ≈ 0.166 → stored as 0
1/8 = 0.125 → stored as 0

╭────────────────────────────────────────╮
│				🌟7. Reciprocal (1/a) 🌟 				  │
╰────────────────────────────────────────╯


import numpy as np
arr1 = np.array([
                    [1, 2],
                    [3, 4]
])
arr2 = np.array([
                    [10, 20],
                    [30, 40]
])

exp = 1 / arr1
print("Reciprocal - Without Function")
print(exp)
print("using Function")
print(np.reciprocal(arr1, arr2))



📌 Output

Reciprocal - Without Function
[[1.         0.5       ]
 [0.33333333 0.25      ]]

using Function
[[1 0]
 [0 0]]
