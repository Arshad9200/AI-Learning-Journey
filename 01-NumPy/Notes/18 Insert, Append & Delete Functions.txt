📌 What is insert()?

The np.insert() function is used to insert one or more elements into a NumPy array at a specified index.

In simple words,

insert() adds a new element at the given position and returns a new array.


Note: If we will pass float value than by default it insert as integer value, not float value.



❓ Why Do We Need insert()?
─────────────────────

We use insert() when we want to:

✅ Add a new element at a specific position.
✅ Insert multiple elements.
✅ Insert rows or columns in a 2-D array.


📚 Syntax

np.insert(array, index, value, axis=None)




⚠️ Important Points --------------

np.insert() does not modify the original array.

It returns a new array with the inserted element(s).

The original array remains unchanged.

In a 2-D array:
	axis=0 → Insert Row
	axis=1 → Insert Column








▓▒░ 💻 1-D ARRAY  ░▒▓



✦ ━━━━━━━━━━━━━━━━━━━━━━━━━━━ ✦
        Insert an Element in a 1-D Array
✦ ━━━━━━━━━━━━━━━━━━━━━━━━━━━ ✦

📝 Example 1: 


import numpy as np

arr = np.array([10, 20, 40, 50])

result = np.insert(arr, 2, 30)

print(result)


📌 Output

[10 20 30 40 50]



💡 Explanation

Original Array

Index : 0   1   2   3
Array :10  20  40  50

Insert 30 at index 2

Result

Index : 0   1   2   3   4
Array :10  20  30  40  50









✦ ━━━━━━━━━━━━━━━━━━━━━━━━━━━ ✦
              Insert Multiple Elements
✦ ━━━━━━━━━━━━━━━━━━━━━━━━━━━ ✦

📝 Example 2: 


import numpy as np

arr = np.array([10, 20, 50])

result = np.insert(arr, 2, [30, 40])

print(result)


📌 Output

[10 20 30 40 50]













✦ ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ ✦
     		  Insert Multiple Elements at Multiple Different Indexes
✦ ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ ✦

📝 Example: 


import numpy as np

arr2 = np.array([1, 3, 5, 7])

print("Original Array:",arr2)

print("After Insert(multiple elements at multiple index):", np.insert(arr2, [1,2, 3], [2, 4, 6]))


📌 Output

After Insert(multiple elements at multiple index): [1 2 3 4 5 6 7]




💡Explanation:

→ Insert 2 at 1 index
→ Insert 4 at 2 index
→ Insert 6 at 3 index










✦ ━━━━━━━━━━━━━━━━━━━━━━━━━━━ ✦
                  Insert at the Beginning
✦ ━━━━━━━━━━━━━━━━━━━━━━━━━━━ ✦

📝 Example 3:

✦ ━━━━━━━━━━━━━━━━━━━━━━━━━━━ ✦
                     Insert at the End
✦ ━━━━━━━━━━━━━━━━━━━━━━━━━━━ ✦

✦ ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ ✦

✦ ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ ✦

📝 Example 5: 

import numpy as np

[100   1   2 100   3   4 100]











▓▒░ 💻 2-D ARRAY  ░▒▓





🎯 Understanding the axis Parameter

Axis							Meaning

axis=0						Insert Row
axis=1						Insert Column
axis=None (Default)				Works on a flattened (1-D) version of the array







✦ ━━━━━━━━━━━━━━━━━━━━━━━━━━━ ✦
       		 Insert a Row (axis=0)
✦ ━━━━━━━━━━━━━━━━━━━━━━━━━━━ ✦

📝 Example 1: 


import numpy as np

arr = np.array([
    [10, 20],
    [30, 40]
])

result = np.insert(arr, 1, [50, 60], axis=0)

print(result)


📌 Output

[[10 20]
 [50 60]
 [30 40]]


💡 Explanation

A new row [50, 60] is inserted at index 1.










✦ ━━━━━━━━━━━━━━━━━━━━━━━━━━━ ✦
       		 Insert a Column (axis=1)
✦ ━━━━━━━━━━━━━━━━━━━━━━━━━━━ ✦

📝 Example 2:

    [10, 20],
    [30, 40]
])

print(result)

📌 Output

[[ 10 100  20]
 [ 30 200  40]]


💡 Explanation

A new column is inserted at index 1.










✦ ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ ✦
        Insert a same element in Row (axis=0)
✦ ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ ✦


📝 Example 3: 


import numpy as np

arr2d = np.array([
    [1, 2, 3],

])

📌 What is append()?

The np.append() function is used to add one or more elements at the end of a NumPy array.



📚 Syntax

np.append(array, values, axis=None)





▓▒░ 💻 1-D ARRAY  ░▒▓





✦ ━━━━━━━━━━━━━━━━━━━━━━━━━━━ ✦
        Append One Element (1-D Array)
✦ ━━━━━━━━━━━━━━━━━━━━━━━━━━━ ✦

📝 Example 1: 

import numpy as np

arr = np.array([10, 20, 30])

result = np.append(arr, 100)

print(result)

📌 Output

[10 20 30 100]



💡 Explanation

The element 100 is added at the end of the array.









✦ ━━━━━━━━━━━━━━━━━━━━━━━━━━━ ✦
        Append Multiple Elements
✦ ━━━━━━━━━━━━━━━━━━━━━━━━━━━ ✦

📝 Example 2: 


import numpy as np

arr = np.array([10, 20, 30])

result = np.append(arr, [40, 50, 60])

print(result)


📌 Output

[10 20 30 40 50 60]










▓▒░ 💻 2-D ARRAY  ░▒▓





✦ ━━━━━━━━━━━━━━━━━━━━━━━━━━━ ✦
        Append a Row (axis=0)
✦ ━━━━━━━━━━━━━━━━━━━━━━━━━━━ ✦

📝 Example 1: 

import numpy as np

arr = np.array([
    [10, 20],
    [30, 40]
])

result = np.append(arr, [[50, 60]], axis=0)

print(result)


📌 Output

[[10 20]
 [30 40]
 [50 60]]



💡 Explanation

A new row is added at the end of the array.

Rows should wrapped with double brackets.









✦ ━━━━━━━━━━━━━━━━━━━━━━━━━━━ ✦
        	Append a Column (axis=1)
✦ ━━━━━━━━━━━━━━━━━━━━━━━━━━━ ✦

📝 Example 2: 


import numpy as np

arr = np.array([
    [10, 20],
    [30, 40]
])

result = np.append(arr, [[100], [200]], axis=1)

print(result)


📌 Output

[[ 10  20 100]
 [ 30  40 200]]



💡 Explanation

A new column is added at the end of each row.

Each element should be wrapped with brackets and than all elements should be wrapped with single brackets.

📌 What is delete()?

The np.delete() function is used to remove one or more elements from a NumPy array.

In simple words,

delete() removes the specified element(s) and returns a new array.





❓ Why Do We Need delete()?

─────────────────────

We use delete() when we want to:

✅ Remove an element from a specific index.
✅ Remove multiple elements.
✅ Delete rows or columns from a 2-D array.
✅ Create a new array without modifying the original one.



📚 Syntax

np.delete(array, index, axis=None)







▓▒░ 💻 1-D ARRAY  ░▒▓




✦ ━━━━━━━━━━━━━━━━━━━━━━━━━━━ ✦
        Delete One Element (1-D Array)
✦ ━━━━━━━━━━━━━━━━━━━━━━━━━━━ ✦


📝 Example 1: 


import numpy as np

arr = np.array([10, 20, 30, 40, 50])

result = np.delete(arr, 2)

print(result)



📌 Output

[10 20 40 50]



💡 Explanation

Original Array

Index : 0   1   2   3   4
Array :10  20  30  40  50
                         ↑
          Delete Index 2


Result After Delete

[10 20 40 50]








✦ ━━━━━━━━━━━━━━━━━━━━━━━━━━━ ✦
        	Delete Multiple Elements
✦ ━━━━━━━━━━━━━━━━━━━━━━━━━━━ ✦

📝 Example 2: 


import numpy as np

arr = np.array([10, 20, 30, 40, 50])

result = np.delete(arr, [1, 3])

print(result)


📌 Output

[10 30 50]


💡 Explanation

Elements at index 1 and index 3 are removed.

















▓▒░ 💻 2-D ARRAY  ░▒▓





✦ ━━━━━━━━━━━━━━━━━━━━━━━━━━━ ✦
       		 Delete a Row (axis=0)
✦ ━━━━━━━━━━━━━━━━━━━━━━━━━━━ ✦

📝 Example 1: 

import numpy as np

arr = np.array([
    [10, 20],
    [30, 40],
    [50, 60]
])

result = np.delete(arr, 1, axis=0)

print(result)


📌 Output

[[10 20]
 [50 60]]


💡 Explanation

The second row (index 1) is deleted.








✦ ━━━━━━━━━━━━━━━━━━━━━━━━━━━ ✦
        	Delete a Column (axis=1)
✦ ━━━━━━━━━━━━━━━━━━━━━━━━━━━ ✦

📝 Example 5: 

import numpy as np

arr = np.array([
    [10, 20, 30],
    [40, 50, 60]
])

result = np.delete(arr, 1, axis=1)

📌 Output

 [40 60]]


💡 Explanation

The second column (index 1) is deleted.
