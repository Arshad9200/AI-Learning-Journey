Example :

• rand()
• round()

• lower()
• count()
• sum()
• max()

╭────────────────────────────────╮
│   🌟📥 STRING FUNCTIONS🌟	    │
╰────────────────────────────────╯

String functions are used to perform an operation on input string and return an output string.




◤━━━━━━━━━━━━━━━━━━━◥
	   1️⃣ UPPER()
◣━━━━━━━━━━━━━━━━━━━◢

It converts the value of the fields to uppercase.


💫Syntax:

SELECT UPPER(column_name) FROM table_name;


👉EXAMPLE:

SELECT UPPER(name) FROM manali_trip;


🔖Output:

UPPER(name)

ARSHAD
AATIF
ABHIJEET
ASHU
OM



💡Issue: Upper method Modified the column name with UPPER(name)




👉HOW TO FIX THE COLUMN NAME ISSUE:👈

After apply upper() method return the column name as alias



👉Example:

SELECT UPPER(name) as NAME FROM manali_trip;

🔖Output:

NAME

ARSHAD
AATIF
ABHIJEET
ASHU
OM












◤━━━━━━━━━━━━━━━━━━━◥
	   2️⃣ LOWER()
◣━━━━━━━━━━━━━━━━━━━◢

It converts the value of the fields to lowercase.

💫Syntax:

SELECT LOWER(column_name) FROM table_name;



👉Example:

SELECT LOWER(name) as name FROM manali_trip;

🔖Output:

name

arshad
aatif
abhijeet
ashu
om











◤━━━━━━━━━━━━━━━━━━━◥
	   3️⃣ LENGTH()
◣━━━━━━━━━━━━━━━━━━━◢

It return the length of the value/characters in a text fields of each columns.


💫Syntax:

SELECT LENGTH(column_name) FROM table_name;



👉Example:

SELECT name, LENGTH(name) as name_length FROM manali_trip; 


🔖Output:

name	name_length

Arshad		6
Aatif		5
Abhijeet	8
Ashu		4
Om			2











◤━━━━━━━━━━━━━━━━━━━◥
	  4️⃣ SUBSTRING()
◣━━━━━━━━━━━━━━━━━━━◢

It extract the sub-string from the string.


💫Syntax:

SELECT SUBSTRING(column_name, first_index, last_index) FROM table_name; 



💡Explanation:

SUBSTRING(name, 1, 3) 
name →  column from which we have to extract sub-string
1 	 →  Starting index 
3 	 →  Ending Index



📍Note: 
It simply works normally means It does not start from 0 as first index. 1 means first index and 3 means third index and 3 is also inclusive.



👉Example:

SELECT name, SUBSTRING(name, 1, 3) as name_substring FROM manali_trip; 



🔖Output:

name	name_substring

Arshad		Ars
Aatif		Aat
Abhijeet	Abh
Ashu		Ash
Om			Om









◤━━━━━━━━━━━━━━━━━━━◥
	   5️⃣ NOW()
◣━━━━━━━━━━━━━━━━━━━◢

SELECT NOW() as time FROM manali_trip;

◤━━━━━━━━━━━━━━━━━━━◥
	 6️⃣ 🔢FORMAT()
◣━━━━━━━━━━━━━━━━━━━◢

The FORMAT() function is used to format a number with commas and a specified number of decimal places.



💡 Syntax

FORMAT(number, decimal_places)


🔹 Example

SELECT name, budget, FORMAT(budget, 3) as format_budget FROM manali_trip; 



Output:

name		budget		format_budget

Arshad		  5000			5,000.000
Aatif			  12000			12,000.000
Abhijeet		  7000			7,000.000
Ashu		  5000			5,000.000
Om			  7500			7,500.000
Vishwa  		  5000			5,000.000
 Sikandar 		  12000		        12,000.000



⚠️ Important: 
FORMAT() returns the result as a string, so it is mainly useful for display/presentation, not further mathematical calculations.













◤━━━━━━━━━━━━━━━━━━━◥
	   7️⃣ CONCAT()
◣━━━━━━━━━━━━━━━━━━━◢

It adds two or more strings together.


💫Syntax:

SELECT CONCAT(column1, column2) FROM table_name; 



👉Example:

SELECT name , CONCAT(name, budget) as Status FROM manali_trip; 



🔖Output:

name		Status

Arshad		Arshad5000
Aatif			Aatif12000
Abhijeet		Abhijeet7000
Ashu		Ashu5000
Om			Om7500













◤━━━━━━━━━━━━━━━━━━━◥
	   8️⃣ REPLACE()
◣━━━━━━━━━━━━━━━━━━━◢

It replaces all occurrences of a sub-string with-in a string with new sub-string of a single row.


💫Syntax:

SELECT name, REPLACE(column_name, 'existing string', 'new_string') FROM table_name; 


👉Example:

SELECT name, REPLACE(name, 'Arshad', 'Arshad Captain') as Updated_name FROM manali_trip; 


🔖Output:

name		updated_name

Arshad		Arshad Captain
Aatif		Aatif
Abhijeet	Abhijeet
Ashu		Ashu
Om			Om














◤━━━━━━━━━━━━━━━━━━━◥
	   9️⃣ TRIM()
◣━━━━━━━━━━━━━━━━━━━◢

It removes leading and trailing spaces (or other specified characters) from a strings


# Note : viswa and sikandar contains extra spaces


💫Syntax:

SELECT TRIM(name) FROM manali_trip; 



👉Example:

SELECT name, LENGTH(name) as OriginalLength, LENGTH(TRIM(name)) as name_after_trim FROM manali_trip; 




🔖Output:

name		OriginalLength		name_after_trim

Abhijeet		 8				8
Ashu		     4				4
Om			     2				2
Vishwa  		 8				6
 Sikandar 	     10				8


Explanation: 

⚠️Before Trim

Name			Length
Vishwa 		→	   8
Sikandar	→	  10



🔦After Trim
Name			Length
Vishwa 		→	   6
Sikandar	→	   8
