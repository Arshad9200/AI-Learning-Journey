SQL (Structured Query Language) is a programming language used to communicate with and manage relational databases.



With SQL, we can:

🔹Create databases and tables
🔹Insert data
🔹Retrieve data
🔹Update data
🔹Delete data
🔹Filter and sort data
🔹Join data from multiple tables

=================
📚 Types of Databases
=================



Databases are mainly classified into the following types:




🔷══════════════════════════════🔷
 1. 🏢 Relational Database (RDBMS)
🔷══════════════════════════════🔷


A relational database stores data in tables, consisting of rows and columns.

It uses SQL (Structured Query Language) to manage data.


Examples:

🔸MySQL
🔸PostgreSQL
🔸Oracle
🔸Microsoft SQL Server
🔸SQLite



👉 Uses SQL to manage data.








🔷══════════════════════════════🔷
  2️⃣ Non-Relational Database (NoSQL)
🔷══════════════════════════════🔷


A non-relational database does not require data to be stored in traditional tables with fixed rows and columns.

It generally provides a flexible schema and is useful for large-scale, rapidly changing, or unstructured/semi-structured data.

Examples:

🔹MongoDB → Document

🔹Redis → Key-Value

🔹Cassandra → Wide-Column

🔹Neo4j → Graph




 TYPE OF Non-Relational Database (NoSQL)

▓▒░ 💻 📄 Document Database  ░▒▓


Stores data as documents, usually in JSON-like format.

👉Example:

🔗 How Do We Communicate with a Database?
✅═════════════════════════════════════✅


We communicate with a database using a Database Management System (DBMS) and a language such as SQL.




The basic flow is:

👨‍💻 User / Application
        ↓
     SQL Query
        ↓
       DBMS
        ↓
    🗄️ Database
        ↓
    Result / Response



👉Example

Suppose we have a MySQL database containing an employees table.

We send an SQL query:

SELECT * FROM employees;



The flow is:


Python / Application
        ↓
SELECT * FROM employees;
        ↓
      MySQL
        ↓
   employees table
        ↓
     Result
