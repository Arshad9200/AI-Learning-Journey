╭────────────────────────────────╮
│       🌟📥 TIMESTAMPS🌟       │
╰────────────────────────────────╯

The TIMESTAMP data type is used for values that contain both date and time parts.



◤━━━━━━━━━━━━━━━━━━━◥
	    1️⃣ TIME
◣━━━━━━━━━━━━━━━━━━━◢ 

It contains only time , format HH:MI:SS







◤━━━━━━━━━━━━━━━━━━━◥
	    2️⃣ DATE
◣━━━━━━━━━━━━━━━━━━━◢ 

It contains only date , format YYYY-MM-DD






◤━━━━━━━━━━━━━━━━━━━◥
	    3️⃣ YEAR
◣━━━━━━━━━━━━━━━━━━━◢ 

It contains only year , format YYYY or YY





◤━━━━━━━━━━━━━━━━━━━◥
	 4️⃣ TIMESTAMP
◣━━━━━━━━━━━━━━━━━━━◢ 

It contains date  and time, format YYYY-MM-DD HH:MI:SS





◤━━━━━━━━━━━━━━━━━━━◥
    5️⃣ TIMESTAMPTZ
◣━━━━━━━━━━━━━━━━━━━◢ 

It contains date , time and time zone

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🔸 SELECT  TIMEOFDAY()       		   ←   PostgreSQL
🔹 SELECT CURRENT_TIMESTAMP() ←   MySQL
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━



📍Note:

TIMEOFDAY() is a PostgreSQL function and is not supported by MySQL. In MySQL, use NOW() or CURRENT_TIMESTAMP() to get the current date and time.

╭────────────────────────────────╮
│      	🌟📥 EXTRACT🌟          │
╰────────────────────────────────╯

The EXTRACT() function extracts a part from a given date value.




Syntax:

🕰️Extract Month -------------

SELECT EXTRACT(MONTH FROM date_field) 
FROM Table;

👉Output:
It return the month of the given time




🕰️Extract Year -------------

SELECT EXTRACT(YEAR FROM date_field) 
FROM Table;

👉Output:
It return the year of the given time




🕰️Extract Day -------------

SELECT EXTRACT(DAY FROM date_field) 
FROM Table;

👉Output:
It return the day of the given time




🕰️Extract Quarter -------------

SELECT EXTRACT(QUARTER FROM date_field) 
FROM Table;

👉Output:
It return the quarter of the given time
