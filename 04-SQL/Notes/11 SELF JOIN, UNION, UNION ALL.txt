╭────────────────────────────────╮
│      📥 SELF JOINS 🌟        	│
╰────────────────────────────────╯


A SELF JOIN is a regular join in which a table is joined to itself

SELF JOINS are powerful for comparing values in a column of rows with same table.


		Table →  employee
---------------------------------------------
emp_id		name		manager_id

	1		Agni				3
	2		Aakash			4
	3		Dharti			2
	4		Vayu			3

-----------------------------------------------




📍Syntax:

SELECT column_name(s)
FROM table_name AS t1
JOIN table_name AS t2
ON t1.col_name = t2.col_name;



🔖Example:

SELECT table1.name AS employee_name , 
		table2.name AS manager_name
FROM employee as table1
JOIN employee as table2
ON table2.emp_id = table1.manager_id;




👉Output:

employee_name		manager_name

Dharti				Aakash
Vayu				Dharti
Agni				Dharti
Aakash				Vayu












╭────────────────────────────────╮
│        🌟📥 UNION 🌟        	│
╰────────────────────────────────╯

The SQL UNION clause/operator is used to combine / concatenate the results of two or more SELECT statements without returning any duplicate rows and keep unique records.

UNION return only unique records.


To use this UNION clause , each SELECT statement must have

* The same number of columns selected and expressions
* The same data type of both table
* Have them in same column order




🔖Syntax:

SELECT column_name(s) FROM TableA
UNION
SELECT column_name(s) FROM TableB






Table1 →  manali_trip
----------------------------------------------
id		name	budget

1		Arshad	5000
2		Aatif		10000
3		Abhijeet	7000
4		Ashu	5000
---------------------------------------------------



Table2 →  goa_trip
----------------------------------------------
id		name	budget

1		Arshad	5000
2		Aatif		10000
5		om		7000
6		vishwa	5000
---------------------------------------------------



👉 Example:

SELECT * FROM manali_trip
UNION
SELECT * FROM goa_trip;




Output:

 id		name	budget

1		Arshad	5000
2		Aatif		10000
3		Abhijeet	7000
4		Ashu	5000
5		om		7000
6		vishwa	5000



💡Note: 
UNION removes the common records and return only unique records.













╭────────────────────────────────╮
│       🌟📥 UNION ALL 🌟       │
╰────────────────────────────────╯

In UNION ALL everything is same as UNION , it combines / concatenate two or more tables but keep all records including duplicates.


Syntax:

SELECT column_name(s) FROM TableA
UNION ALL
SELECT column_name(s) FROM TableB




👉 Example:

SELECT * FROM manali_trip
UNION ALL
SELECT * FROM goa_trip;




Output:

 id		name		budget

1		Arshad		5000
2		Aatif		10000
3		Abhijeet	7000
4		Ashu		5000
1		Arshad		5000
2		Aatif		10000
5		om			7000
6		vishwa		5000



💡Note: 
UNION returns all data , unique and common both records.
