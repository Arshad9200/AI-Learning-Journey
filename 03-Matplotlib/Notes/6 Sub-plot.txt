╭────────────────────────────────────╮
│ 				🌟🥧SUB PLOT 🌟				│
╰────────────────────────────────────╯


A subplot is used when you want to display multiple plots inside a single figure.

For example, instead of creating:

📈 Graph 1
📈 Graph 2
📈 Graph 3




separately, you can place them together:

┌───────────────┬───────────────┐
│   		📈 Plot 1   	  │   		📊 Plot 2   	   │
├───────────────┼───────────────┤
│   		📍 Plot 3   	  │   		🥧 Plot 4  	   │
└───────────────┴───────────────┘



-------------------------------
🔹 Basic Syntax🔹
-------------------------------

plt.subplot(rows, columns, position)



Parameters:

🔸rows → number of rows
🔸columns → number of columns
🔸position → position of the current plot




----------------------
For example:
-----------------------

plt.subplot(2, 2, 1)

means:

2 rows
2 columns
Position 1





💡Important:

✔ Keep the same grid for related subplots like (2, 3, 1) (2, 3, 2)  (2, 3, 3) (2, 3, 4)  (2, 3, 5)
✔ Position starts from 1
✔ Position must exist within the grid
✔ Set figsize before creating subplots
✔ Use plt.show() after all charts



👉🏻Example:




import matplotlib.pyplot as plt
import numpy as np

plt.figure(figsize=(10, 7))

# Line Chart
days = ["Mon", "Tue", "Wed", "Thu", "Fri"]
day_sales = [200, 160, 210, 300, 500]
plt.subplot(2, 3, 1)
plt.plot(days, day_sales)


# # Bar chart
month = ["Jan", "Feb", "Mar", "Apr", "May"]
month_sales = [2000, 1600, 2150, 3000, 5500]
plt.subplot(2, 3, 2)
plt.bar(month, month_sales)

# Histogram
year_sales = [
    20000, 16000, 21500, 30000, 55000,
    25000, 18000, 32000, 45000, 28000,
    35000, 22000, 50000, 40000, 30000
]
plt.subplot(2, 3, 3)
plt.hist(year_sales, bins=10, edgecolor="Red")

# Pie Chart
decade = [1980, 1990, 2000, 2010, 2020]
decade_sales = [200000, 160000, 215500, 300000, 450000]
plt.subplot(2, 3, 4)
plt.pie(decade_sales, labels=decade, autopct="%1.1f%%")


# Scatter Chart
offers_per= [np.random.randint(0, 100) for _ in range(0, 100)]
offers_date= [np.random.randint(0, 100) for _ in range(0, 100)]
plt.subplot(2, 3, 5)
plt.scatter(offers_per, offers_date)

plt.title("Master Sales Report")
plt.show()





👉🏻Output:


It create a Grid of row=2, column = 3, keep chart based on position
Based on the data, Subplot creates 5 different charts at their given positions
