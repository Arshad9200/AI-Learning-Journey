After creating a chart, you can save it as an image file using:

plt.savefig()




----------------------------
🔹 Basic Syntax
----------------------------

plt.savefig("filename.png")





👉🏻Example:

import matplotlib.pyplot as plt

x = [1, 2, 3, 4, 5]
y = [10, 20, 30, 40, 50]

plt.plot(x, y)

plt.title("Sales Report")

plt.savefig("sales.png")

plt.show()



👉🏻Output:

This saves the chart as:  sales.png










◤━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━◥
       📁 Save to a Specific Location
◣━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━◢


You can provide the complete path:

plt.savefig(r"C:\Users\DELL\Desktop\sales.png")



💡Why r?

On Windows, paths contain \.

like: C:\Users\DELL\Desktop

Using r creates a raw string, so Python doesn't treat \ as an escape character.

r"C:\Users\DELL\Desktop\sales.png"










◤━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━◥
       		🖼️ Different File Formats
◣━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━◢



Matplotlib can save charts in different formats.

🔸plt.savefig("chart.png")

🔸plt.savefig("chart.jpg")

🔸plt.savefig("chart.pdf")

🔸plt.savefig("chart.svg")





📍Common formats:

Format					Use

   .png					General use, high quality
   .jpg					Smaller image files
   .pdf					Documents/reports
   .svg					Scalable graphics







◤━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━◥
       	   ⭐ Save With High Resolution
◣━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━◢


💡For better image quality:

plt.savefig("sales.png", dpi=300)

dpi means dots per inch.

Higher DPI → better image quality.



👉🏻For example:

plt.savefig("sales.png", dpi=300)

is commonly useful when you need a high-quality image.








◤━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━◥
       	   🧹 Remove Extra White Space
◣━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━◢


You can use:

plt.savefig("sales.png", bbox_inches="tight")

Or combine both:

plt.savefig(
    "sales.png",
    dpi=300,
    bbox_inches="tight"
)










◤━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━◥
       	 ⚠️ Important: Save Before show()
◣━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━◢


💡Prefer:

plt.plot(x, y)

plt.savefig("sales.png")

plt.show()




⚠️Rather than:

plt.plot(x, y)

plt.show()

plt.savefig("sales.png")




📍Why?

plt.show() displays the figure, and depending on the environment/backend, the figure may be cleared or closed afterward. So save the chart before displaying it.
